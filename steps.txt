# Project Instructions

This repository follows specification-driven development.

Before implementing a feature:

1. Read the relevant file under /specs.
2. Identify the applicable requirements.
3. Do not invent requirements.
4. Implement the smallest change satisfying the specification.
5. Add tests covering acceptance criteria.
6. Run existing tests.
7. Report which requirements were implemented.

Code should remain simple enough for instructional use.
